# AI 활용 작업 로그

AI를 사용한 중요한 작업마다 Markdown 파일 하나를 생성합니다.

권장 파일명:

`YYYY-MM-DD-작업명.md`

각 로그에는 다음 내용을 남깁니다.

- 작업 날짜
- 사용한 AI 도구와 모델
- 해결하려는 문제 또는 목적
- 주요 프롬프트·지시 사항
- AI가 제안하거나 생성한 결과
- 사람이 검토·수정한 내용
- 실제 게임에 반영한 파일 또는 기능
- 제외한 결과와 제외 이유
