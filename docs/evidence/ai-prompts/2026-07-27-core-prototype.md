# 코어 플레이 프로토타입 구현

- 날짜: 2026-07-27
- 도구·모델: Codex (세부 모델명은 최종 제출 문서 작성 시 실행 기록 기준으로 확정)
- 작업 목적: 확정된 게임 규칙을 모바일 브라우저에서 직접 조작할 수 있는 1인 코어 프로토타입으로 구현하고 자동 검증 기반 마련
- 관련 파일·기능: `package.json`, `src/`, `tests/`, `.github/workflows/deploy-pages.yml`

## 주요 프롬프트·지시 사항

사용자가 확정한 다음 게임 규칙과 제출 조건을 구현 기준으로 사용했다.

- 메뉴 50개 풀에서 한 판에 20개 출제
- 마음에 드는 메뉴는 닫힌 원형 제스처로 최대 2개까지 포획
- 나머지 메뉴는 드래그로 베고, 실제 면적이 50:50에 가까울수록 높은 점수 부여
- 포획하지 않은 메뉴의 베기 점수만 평균 내 최종 점수 계산
- 모바일 세로 화면 우선, 데스크톱 마우스도 지원
- 브라우저에서 실행하고 GitHub Pages로 제출할 수 있는 전체 소스와 배포 흐름 구성

## 생성·제안 결과 요약

- Vite·TypeScript·Phaser 기반 프로젝트와 모바일 세로형 캔버스 구성
- 열린 드래그는 베기, 닫히고 메뉴 중심을 포함한 경로는 포획으로 분류
- 원과 직선의 교차점 및 원호 면적을 이용한 실제 면적 비율 점수 계산
- 고정 시드 난수와 시간대 가중치를 사용하는 50개 메뉴 데이터 및 20개 비복원 추출
- 최대 포획 횟수, 미스 처리, 평균 점수, 공동 순위 규칙을 순수 함수로 분리
- Vitest 단위 테스트와 Playwright 브라우저 테스트 기반 구성
- `main` 푸시 시 테스트·빌드 후 `dist/`를 게시하는 GitHub Pages 워크플로 구성

## 검토 및 수정

- 이동 중인 메뉴를 원으로 그리는 동안 제스처와 대상의 상대 위치가 달라지는 문제를 확인해, 메뉴 근처에서 입력이 시작되면 판정이 끝날 때까지 해당 메뉴의 이동을 잠시 멈추도록 조정했다.
- 시작점과 끝점만 잇는 선 대신 실제 드래그 궤적이 원의 밖에서 안으로 들어갔다 다시 나간 첫 교차 구간으로 베기를 판정하도록 보강했다.
- 면적이 없는 왕복선과 자기 교차 경로가 포획으로 오인되지 않게 최소 면적·단순 경로를 검사하고, 낙하 정지 기회는 메뉴당 한 번으로 제한했다.
- 닫힌 경로가 포획 조건을 만족하지 않을 때 시작점과 끝점이 같아 베기 계산이 실패할 수 있는 예외를 방어했다.
- 기하·게임 규칙·메뉴 데이터에 대한 단위 테스트 60개를 통과시켰고 TypeScript 검사와 프로덕션 빌드를 실행해 확인했다.
- 390×844 모바일 화면과 데스크톱 화면을 실제 브라우저에서 확인하고 파비콘 경로 오류를 수정했다.
- 브라우저 E2E에서 논리 좌표를 실제 스케일된 캔버스 좌표로 변환하도록 보정했으며, 데스크톱 핵심 제스처와 데스크톱·모바일 표시 검증 결과 4개 통과·2개 의도적 제외를 확인했다.

## 실제 반영 내용

- 1인 코어 플레이: 메뉴 낙하, 베기, 포획, 피드백, 결과 표시
- 도메인 로직: 기하 판정, 점수 계산, 덱 생성, 최종 평균과 순위
- 데이터: 디저트를 제외한 한국 일상식 메뉴 50개
- 품질 기반: 타입 검사, 단위 테스트, 브라우저 E2E, 프로덕션 빌드 명령
- 제출 기반: 상대 경로 정적 빌드와 GitHub Pages 자동 배포 워크플로

## 사람의 판단과 수정이 필요한 영역

- 음식 이미지, 배경 아트, 효과음과 AI 음성의 최종 스타일 승인
- 실제 Android·iPhone 터치 입력과 저사양 기기 성능 검증
- Firebase 기반 2~8인 방, QR 초대, 공정한 공통 시드와 결과 집계
- GitHub 저장소와 Pages URL, YouTube 영상 URL, 최종 PDF의 제출 정보 입력

## 제외한 내용 및 이유

- QR·멀티플레이 방: 코어 제스처와 점수 재미를 먼저 검증하기 위해 다음 마일스톤으로 분리
- 외부 음식 이미지·사운드·폰트: 출처와 라이선스가 확정되기 전에는 포함하지 않고 도형·시스템 폰트로 대체
- 실제 유명인·방송 밈 음성 모사: 퍼블리시티권과 저작권 위험을 피하고 독자 문구·독자 음성으로 제작하기 위해 제외
- 업적, 도구 스킨, 디저트 모드: 해커톤 MVP 범위를 지키기 위해 제출 이후 기능으로 유지
