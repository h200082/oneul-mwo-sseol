# 해커톤 제출 환경 구성

- 날짜: 2026-07-27
- 도구·모델: Codex (세부 모델명은 최종 문서 작성 시 실행 기록 기준으로 확정)
- 작업 목적: NHN 게임 제작 해커톤의 필수 제출물 5종을 누락 없이 준비할 수 있는 저장소 구조 구성
- 관련 파일·기능: 저장소 기본 문서, 제출 체크리스트, PDF 원본 템플릿, AI·라이선스 증빙 구조

## 주요 프롬프트·지시 사항

사용자가 제공한 사전 과제 제출 기준에 맞춰, 앞으로 제작할 게임의 개발 및 제출 환경을 구성하도록 요청했다.

핵심 요구 사항은 다음과 같다.

- 플레이 가능한 웹 또는 모바일 빌드와 전체 소스 코드
- 30~60초 실제 플레이 영상
- 게임 소개 및 설명 PDF
- AI 활용 기술 PDF
- 2인 이상 팀일 경우 팀원 롤 기술서 PDF
- 외부 에셋과 오픈소스의 출처·라이선스 기록
- AI 도구, 주요 프롬프트, 활용 내역 기록

## 생성·제안 결과 요약

- 필수 제출물별 체크리스트 작성
- 게임 소개서, AI 활용 기술서, 팀원 롤 기술서의 편집 원본 작성
- AI 활용 로그 템플릿과 외부 에셋·라이선스 기록표 작성
- 최종 PDF를 별도로 관리하는 폴더 구조 작성

## 검토 및 수정

- 아직 게임 내용과 기술 스택이 정해지지 않았으므로 게임 코드와 배포 자동화는 생성하지 않았다.
- 게임 설명을 받은 뒤 웹 기술 스택과 GitHub Pages 배포 방식을 확정하기로 했다.
- 개인 참가 여부가 확인되지 않아 팀원 롤 기술서는 선택 제출 상태로 유지했다.
