# 베기 쾌감·점수별 임팩트 연출 개선

- 날짜: 2026-08-09
- 도구·모델: OpenAI Codex
- 작업 목적: 음식 베기의 판정 정확도는 유지하면서 점수에 따라 시각·음향·진동의 손맛이 달라지는 모바일 친화적 연출 구현
- 관련 기능: 베기 판정 후 연출, 칼 궤적, 음식 조각 분리, 점수 팝업, 절차형 효과음, 진동, 동작 감소 설정

## 사용자 요구와 문제 정의

사용자는 베는 행위 자체에서 더 큰 쾌감이 느껴지길 원했고, 단순히 이펙트 수를 늘리는 방식보다 게임에 맞는 방향을 먼저 추천해 달라고 요청했다. 검토 결과 기존 구현은 베기 정확도 등급이 달라도 조각 분리, 칼선, 카메라 반응 등 핵심 시각 연출이 거의 동일해 낮은 점수와 높은 점수의 손맛 차이가 작았다.

AI는 귀여운 음식 추천 게임의 분위기를 해치지 않는 클린 셰프 아케이드 방향을 제안했다. 피나 지저분한 소스가 튀는 표현은 제외하고, 짧고 선명한 칼선·정돈된 조각 분리·추상적인 빵가루와 별가루·점수별 감각 피드백을 한 타이밍에 결합하는 것을 목표로 삼았다.

## 주요 프롬프트·지시 사항

- 베기 정확도에 따라 체감이 달라지는 4단계 SliceImpactProfile을 만든다.
- 순간 정지는 판정이 끝난 음식 조각 연출에만 적용하고 게임 장면·낙하 음식·입력 전체를 멈추지 않는다.
- 조각은 짧게 붙잡힌 뒤 빠르게 벌어지고 회전하며 사라지는 2단계 동작으로 만든다.
- 드래그 궤적은 최근 포인터 점만 사용하며 속도와 수명에 따라 가늘어지는 tapered trail로 표현한다.
- 추상 파편만 사용하고 한 번의 베기에 최대 8개로 제한한다.
- 모바일 성능을 위해 블러·후처리 필터를 사용하지 않고 임시 오브젝트를 짧은 시간 안에 정리한다.
- 칼바람, 절단 충격, 고득점 반짝임의 3층 절차형 사운드와 점수별 진동을 결합한다.
- 동작 감소 설정이 감지되면 순간 정지, 카메라 흔들림, 회전, 파편 수와 이동량을 축소한다.

## AI가 제안·생성한 결과

### 점수별 SliceImpactProfile

베기 결과를 낮은 정확도, 보통, 훌륭함, 완벽의 4단계 프로필로 나누고 다음 값을 한곳에서 관리하도록 구성했다.

- 로컬 hit-stop 길이
- 음식 조각의 초기 분리 거리, 최종 이동 거리, 회전량
- 칼선과 점수 팝업의 색·크기·지속 시간
- 카메라 흔들림 세기와 시간
- 추상 파편 개수와 속도
- 절차형 효과음 및 진동 단계

정확도가 높을수록 피드백이 커지되 낮은 점수도 판정 성공 여부를 알 수 있는 최소 반응은 유지한다. 시각·사운드·진동은 동일한 점수 등급을 공유한다.

### 전역 정지 없는 로컬 hit-stop

과거 입력 중 음식이 공중에서 멈추는 문제를 다시 만들지 않도록 Phaser 장면, 전체 시간 배율, 입력, 다른 음식의 낙하를 정지하지 않는다. 판정이 완료되어 원본에서 분리된 두 시각 조각의 출발만 등급별로 짧게 늦춘다. 이 방식은 타격 순간의 무게감을 주면서 게임 진행과 포인터 응답성을 유지한다.

### 2단계 조각 분리와 칼 궤적

- 1단계: hit-stop 직후 절단선의 법선 방향으로 두 조각이 짧고 빠르게 벌어진다.
- 2단계: 각 조각이 반대 방향으로 회전하고 조금 더 멀어지며 투명해진다.
- 드래그 중에는 전체 입력 이력을 남기지 않고 최근 점만 보관한다.
- 오래된 궤적은 먼저 사라지고 끝부분은 가늘어져 밝은 칼날처럼 보이게 한다.

### 절제된 파편과 모바일 예산

추상 파편은 절단 방향을 따라 퍼지는 아이보리·금색 계열의 점, 빵가루, 별 모양으로 제한한다. 음식물이나 소스가 넘치거나 튀는 표현은 사용하지 않는다.

- 한 번의 베기에 파편 최대 8개
- 블러, 셰이더, 색수차 등 화면 후처리 필터 없음
- 임시 그래픽과 조각은 약 0.5초 안에 파괴
- 최근 궤적 점 수에 상한 적용
- 연속 베기에서도 파편과 트윈이 계속 쌓이지 않도록 종료 시 정리

### 3층 절차형 사운드·진동

외부 음원을 추가하지 않고 Web Audio 기반 절차형 음향을 사용한다.

1. 손가락 이동 속도를 느끼게 하는 짧은 칼바람
2. 판정 순간을 강조하는 낮고 짧은 절단 충격
3. 높은 정확도에서만 더해지는 밝은 반짝임

진동은 낮은 등급의 짧은 단발부터 완벽 등급의 짧은 이중 패턴까지 차등 적용한다. 브라우저나 기기가 진동을 지원하지 않아도 게임 진행에는 영향을 주지 않는다.

## 코드 생성과 사람 검토의 구분

### AI가 생성·보조한 부분

- 기존 베기 연출과 감각 피드백 코드의 구조 분석
- SliceImpactProfile의 4등급 값과 적용 구조 초안
- 로컬 hit-stop, 2단계 분리, tapered trail, 추상 파편 구현 초안
- 절차형 사운드 레이어와 진동 패턴 연결
- 동작 감소 및 모바일 성능 제한 로직
- 점수 경계와 정리 동작을 확인하는 단위 테스트 초안

### 사람이 검토·결정한 부분

- 음식의 귀여움과 식욕을 유지하는 클린 셰프 아케이드 콘셉트 승인
- 피·소스 튐, 과한 화면 흔들림, 전역 일시정지, 무거운 후처리 효과 제외
- 정확도별 연출 차이가 실제 점수와 자연스럽게 느껴지는지 판단
- 기존 베기 판정, 음식 이미지, 게임 규칙과 포획 방식이 바뀌지 않는지 확인
- 모바일 실기기에서 최종 효과 강도와 진동 세기를 다시 조정할 항목으로 유지

AI가 제안한 수치는 최종 디자인 결정이 아니라 구현 초기값이다. 실제 기기에서 사람이 반복 플레이하고 피로감·가독성·프레임 유지 여부를 확인한 뒤 조절한다.
