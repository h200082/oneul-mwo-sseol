# 크림 스카이 타이틀·홈 레이아웃 정리

- 날짜: 2026-08-08
- 도구·모델: OpenAI Codex
- 작업 목적: 어두운 첫 화면을 밝고 식욕을 돋우는 색으로 바꾸고, 홈의 설정과 친구 참가 기능을 간결하게 재구성
- 관련 파일: src/app/AppController.ts, src/app/app.css, tests/e2e/home-layout.spec.ts

## 사용자 요구

- 검은색에 가까운 첫 화면 배경을 더 밝고 게임에 어울리는 색으로 바꾼다.
- 효과음·진동 설정은 홈 우측 상단의 작은 버튼으로 정리한다.
- 친구 방 참가는 게임 방법처럼 접고 펼칠 수 있게 만든다.
- 핵심 시작 동작이 먼저 보이는 깔끔한 홈 레이아웃을 만든다.

## 색상 분석과 선택

기존 320×568 타이틀 캡처를 양자화해 확인한 결과 짙은 남색 두 색이 화면의 약 74.3%를 차지해 검은 배경처럼 느껴졌다. 고양이와 음식은 주황·갈색 계열이 중심이므로, 전체를 노랑이나 크림으로만 밝히면 대상이 배경에 묻힐 수 있다.

최종적으로 크림 스카이 팔레트를 선택했다.

| 용도 | 색상 | 이유 |
|---|---|---|
| 타이틀·홈 바깥 | #FFF7E8 → #FDE9DD | 식사 게임다운 따뜻함 |
| 음식 애니메이션 무대 | #DDF3F5 → #CFEAE7 | 주황·갈색 음식과 고양이의 보색 대비 |
| 카드 | #FFFDF8 | 순백보다 부드러운 표면 |
| 주요 글자 | #243447 | 밝은 배경에서 높은 가독성 |
| 보조 글자 | #5F6F7B | 본문 대비 유지 |
| 청록 강조 | #0B746C | 참가·설정 상태 |
| 코랄 강조 | #BD4938, #F2755F | 제목과 핵심 시작 버튼 |

주요 텍스트와 버튼 대비는 약 4.72:1~11.90:1 범위로 조정했다. 타이틀과 홈만 밝게 하고 실제 게임·로비·결과 화면은 기존의 어두운 아케이드 팔레트를 유지했다.

## 홈 정보 구조

### 효과음·진동

기존에 헤더 아래 한 줄을 차지하던 텍스트형 설정 버튼을 우측 상단 아이콘 버튼으로 옮겼다.

- 시각 크기와 실제 버튼 크기: 44×44px
- 효과음: ♪
- 진동: ≋
- 켜짐·꺼짐은 배경과 테두리 색, aria-pressed로 표현
- aria-label은 효과음 끄기/켜기, 진동 끄기/켜기로 유지
- 게임 중 HUD 설정과 같은 저장 상태를 공유

버튼을 더 작게 보이게 하면서도 모바일 터치 권장 영역은 줄이지 않았다.

### 친구 방 참가

기존에 항상 펼쳐져 있던 코드 입력·QR 기능을 native details 요소로 변경했다.

- 일반 홈: 기본 접힘
- 요약 행: 친구 방 참가
- 펼침 내용: 방 코드 입력, 참가 버튼, 앱 QR 스캔
- 게임 방법과 독립적으로 열고 닫을 수 있음
- QR 초대 링크로 접속: 타이틀을 우회하고 친구 참가 영역을 자동으로 펼침
- 초대 취소: 일반 홈으로 돌아가며 다시 접힌 상태

따라서 첫 화면에는 닉네임·식사 시간·혼자 하기·방 만들기가 우선 보이고, 보조 기능은 한 줄짜리 카드 두 개로 정리된다.

## 반응형·접근성 검토

- 320×568 및 Pixel 7 화면에서 가로 넘침 없음
- 설정 버튼이 우측 상단에 있고 시작 카드와 겹치지 않음
- 두 설정 버튼 모두 44×44px 터치 영역
- 친구 참가 summary는 키보드 Enter로 열고 닫을 수 있음
- 동작 감소 설정에서는 고양이·음식 반복 애니메이션 중지
- 밝은 배경 fallback을 실제 background-color로 유지
- screen root가 숨겨지면 밝은 외곽도 해제되어 게임 배경이 기존 어두운 색으로 복귀
