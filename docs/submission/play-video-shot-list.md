# 실제 플레이 영상 샷 리스트

## 목표와 원칙

- **목표 길이:** 55~58초. 제출 허용 범위는 30~60초다.
- **화면:** 현재 게임 빌드를 실제로 조작한 장면만 사용한다.
- **내부 보수 편집 원칙(공식 요구사항 아님):** 일반적인 컷 편집, 앞뒤 트림, 크롭, 크기 조정과 음량 정리만 사용한다.
- **금지:** AI 생성 영상, AI로 만든 보충 장면, 다른 사람의 플레이 영상, 스톡 영상, 합성 플레이, AI 보이스오버를 사용하지 않는다.
- 게임에 실제로 들어 있는 BGM·효과음·나레이션은 플레이 화면과 함께 그대로 녹음할 수 있다.
- 디버그 패널, 브라우저 개발자 도구, 개인 알림과 비공개 정보는 영상에 노출하지 않는다.

### 길이 조정

- 30초로 줄일 때는 방 생성·로비를 합쳐 6초 이내로 만들고, 메인 플레이 두 장면과 결과는 남긴다.
- 60초에 가깝게 늘릴 때는 튜토리얼을 길게 설명하기보다 실제 두 번째 플레이어의 조작과 결과 동기화를 추가한다.
- 핵심 플레이인 베기, **음식 위 0.32초 길게 눌러 포획(14px 이동 시 베기로 전환), 포획 최대 2개**, 멀티플레이 결과 중 하나라도 빠지면 다시 촬영한다.

## 비AI 편집 확인

- [ ] 영상 생성·장면 확장·프레임 생성·배경 교체·AI 자동 보이스오버 기능을 사용하지 않았다.
- [ ] 모든 플레이 장면은 이 프로젝트의 실제 빌드에서 직접 녹화했다.
- [ ] 외부 게임 영상이나 스톡 영상을 섞지 않았다.
- [ ] 속도를 과도하게 바꿔 실제 조작이나 동기화가 다르게 보이게 하지 않았다.
- [ ] 추가 음성 설명이 필요하면 AI 음성을 넣지 않고, 실제 UI와 짧은 일반 자막만 사용한다.
- [ ] 최종 영상이 30~60초인지 파일 자체의 재생 시간으로 확인했다.
