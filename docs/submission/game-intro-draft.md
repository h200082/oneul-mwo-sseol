# 뭐 먹을 거냥? - 게임 소개 및 설명 문서 (사전 제출본)

> 상태: 제출 전 링크 확인 필요. GitHub Pages 배포와 YouTube 업로드 완료 후 링크를 최종 확정한다.

## 한 줄 소개

먹고 싶은 메뉴는 포획하고 나머지는 정확히 반으로 썰어, 최대 8명의 식사 내기 순위와 메뉴 취향을 함께 확인하는 브라우저 파티게임.

## 게임 개요

- 장르: 캐주얼 아케이드 · 메뉴 선택 파티게임
- 플랫폼: 모바일·PC 웹 브라우저
- 플레이 인원: 혼자 하기 또는 온라인 방 2~8명
- 한 판 길이: 약 45~60초
- 한 판 구성: 전체 음식 50종 중 결정적으로 선택된 20종
- 핵심 재미: 음식 실루엣을 정확히 반으로 가르는 손맛, 먹고 싶은 메뉴를 포획하는 선택, 짧은 문구와 AI 합성 나레이션이 만드는 코미디 리듬

## 플레이 목표

화면 아래로 떨어지는 음식 20개를 처리해 가능한 높은 평균 정확도를 기록한다. 먹고 싶은 음식은 최대 2개까지 포획할 수 있다. 방 플레이에서는 모든 참가자가 같은 음식 순서로 플레이하고 공동 결과 화면에서 순위와 포획 메뉴를 비교한다.

## 조작 방법

1. 베기: 음식의 한쪽 테두리에서 반대쪽 테두리까지 드래그한다.
2. 포획: 먹고 싶은 음식을 0.32초 동안 길게 누른다. 한 판에 최대 2개까지 가능하다.
3. 입력 전환: 길게 누르는 중 14px 이상 움직이면 포획을 취소하고 같은 입력이 베기로 전환된다.
4. 짧은 탭: 아무 동작도 하지 않는다.

## 점수와 종료 조건

- 베기 정확도 = `100 × (1 - |A - B| ÷ (A + B))`
- A와 B는 실제 음식 알파 실루엣을 베었을 때 양쪽에 남은 가중 면적이다.
- 포획한 음식은 평균 정확도 계산에서 제외된다.
- 베지도 포획하지도 못한 음식은 0점이다.
- 20개 음식을 모두 처리하면 라운드가 종료된다.

## 게임 모드

### 혼자 하기

바로 20개 음식 라운드를 시작하고 개인 결과를 확인한다. 튜토리얼은 선택 사항이며 일반 게임 시작 시 강제로 재생되지 않는다.

### 함께 하기

- 방 생성 후 QR 코드, 초대 링크 또는 8자리 코드로 참가
- 2~8명 지원
- 준비 버튼 없이 방장이 시작하면 참가자 명단을 잠그고 같은 20종 덱을 선로딩
- 4초 카운트다운 뒤 동시 시작
- 모든 결과가 도착하거나 서버 마감 조건이 충족되면 공동 순위 표시
- 내기 규칙: 꼴찌가 1등에게 1인분을 산다. 최종 식사 메뉴는 게임이 자동으로 정하지 않는다.

## 실행 방법

1. 최신 Chrome, Edge, Safari 등 웹 브라우저로 플레이 링크를 연다.
2. 소리와 진동을 원하는 경우 브라우저의 오디오 재생과 진동 권한을 허용한다.
3. 모바일 방 참가 시 같은 링크나 QR을 이용한다. QR 카메라 스캔은 HTTPS 환경이 필요하다.
