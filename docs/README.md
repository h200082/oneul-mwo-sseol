# 제출 문서 관리

## 폴더 구조

- `source/`: 내용을 계속 수정하는 문서 원본
- `final/`: 제출 시점에 확정한 PDF
- `evidence/`: AI 프롬프트, 생성·수정 내역, 외부 에셋 출처 등 기술 문서의 근거

## 작업 원칙

1. 개발 중에는 `source/`와 `evidence/`를 함께 갱신합니다.
2. 외부 이미지·사운드·폰트·코드·오픈소스를 추가하는 즉시 출처와 라이선스를 기록합니다.
3. AI를 사용한 작업은 도구, 목적, 주요 지시, 결과 반영 여부를 기록합니다.
4. 제출 직전에 원본을 PDF로 변환하고 화면과 링크를 검수한 뒤 `final/`에 저장합니다.
