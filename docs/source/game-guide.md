# 오늘 뭐 썰? — 게임 소개 및 설명

## 기본 정보

- 게임 제목: **오늘 뭐 썰?**
- 한 줄 소개: 먹고 싶은 메뉴는 포획하고 나머지는 정확히 반으로 썰어, 최대 8명의 식사 내기 순위와 메뉴 취향을 함께 확인하는 브라우저 파티게임
- 장르: 캐주얼 아케이드·메뉴 선택 파티게임
- 지원 환경: 모바일·데스크톱 웹 브라우저
- 권장 플레이 시간: 한 판 약 45~60초

## 게임 개요

`오늘 뭐 썰?`은 메뉴를 강제로 하나로 결정하는 게임이 아니다. 음식 20개를 베거나 최대 2개까지 포획하며 실력 순위를 정하고, 결과 화면에서 참가자별 포획 메뉴와 가장 많이 겹친 메뉴를 보여줘 함께 먹을 음식의 합의를 돕는다.

방 대전에서는 꼴찌가 1등의 식사 1인분을 부담한다. 실제 메뉴와 가격, 구매 범위는 참가자들이 결과를 보고 합의한다.

## 플레이 목표

- 먹고 싶은 음식은 약 0.3초 동안 길게 눌러 포획한다.
- 나머지 음식은 중심에 가깝게 드래그해 두 면적을 최대한 비슷하게 나눈다.
- 놓치지 않고 높은 평균 정확도를 기록한다.
- 방 플레이가 끝나면 전체 순위와 서로 겹친 포획 메뉴를 확인한다.

## 조작 방법

| 입력 | 동작 |
|---|---|
| 음식 위를 가로지르는 드래그 | 음식 베기 |
| 음식 위를 약 0.3초 동안 길게 누르기 | 메뉴 포획 |
| 길게 누르는 중 14px를 넘겨 움직이기 | 포획 대기를 취소하고 베기로 전환 |
| 짧은 탭 | 행동하지 않음 |

포획은 한 판에 최대 2번이며 반드시 사용할 필요는 없다. 드래그하거나 길게 누르는 동안에도 음식은 계속 낙하한다.

## 효과음과 진동 설정

홈에서 `효과음 ON/OFF`와 `진동 ON/OFF`를 따로 설정할 수 있다. 설정은 같은 브라우저에 저장되며 게임 중에는 화면 오른쪽 위의 `♪`, `VIB` 버튼으로 빠르게 바꿀 수 있다.

- 베기 정확도, 포획, 놓침, `FINAL 5`, 결과마다 짧은 효과가 한 번씩 재생된다.
- 방 플레이 효과음은 여러 휴대전화가 함께 재생되는 상황을 고려해 솔로보다 작다.
- 효과음은 외부 사운드 파일 없이 Web Audio로 실행 중 직접 생성한다.
- 진동은 표준 Vibration API를 지원하는 기기에서만 동작한다.
- iPhone 등 진동 미지원 환경에서는 `진동 미지원`으로 표시되며 효과음과 화면 연출은 정상 동작한다.
- 소리와 진동을 모두 꺼도 판정 문구·색상·팝업은 그대로 표시된다.

## 처음 플레이할 때의 안내

홈의 `게임 방법`은 기본적으로 접힌 상태다. 펼치면 베기, 포획, 놓침과 평균 점수 규칙을 게임 시작 전에 확인할 수 있다.

혼자 하기를 새로 시작하면 실제 첫 라운드 전에 조작 안내가 나타난다.

- 드래그는 가운데를 지날수록 높은 점수를 얻는다.
- 먹고 싶은 음식은 0.3초 동안 길게 누르며 포획은 최대 2회다.
- 놓친 음식은 0점이고, 포획한 음식은 평균 점수에서 제외된다.
- 안내는 약 2.3초 뒤 자동으로 닫히며 화면을 탭하면 바로 시작할 수 있다.

방 플레이에는 별도의 준비나 연습 단계를 넣지 않는다. 공통 3초 카운트다운에 `드래그해서 베기 · 0.3초 꾹 눌러 포획`을 표시하고, 기존의 같은 시작 시각과 같은 덱 규칙을 유지한다.

실제 플레이의 처음 세 음식에는 상황별 안내가 표시된다.

1. 첫 번째 음식: 화면을 가로질러 드래그하는 베기 안내
2. 두 번째 음식: 먹고 싶을 때 움직이지 않고 0.3초 누르는 포획 안내
3. 세 번째 음식: 포획은 선택이며 정확히 반으로 썰 수 있다는 안내

네 번째 음식부터는 음식 이름과 두 조작을 함께 보여주는 짧은 안내로 전환한다.

## 게임 진행

### 혼자 하기

1. 홈에서 점심 또는 저녁을 선택한다.
2. `혼자 하기`를 누르고 시작 안내를 확인하거나 화면을 탭해 넘긴다.
3. 음식 20개를 차례로 베거나 최대 2개 포획한다.
4. 개인 평균 정확도, 놓친 음식 수, 포획 메뉴를 확인한다.
5. 다시 하기 또는 홈으로 이동한다.

### 방 플레이

1. 방장이 방을 만들고 QR 코드, 링크 또는 8자리 코드를 공유한다.
2. 2~8명이 입장하면 방장이 참가자 준비 버튼 없이 게임을 시작한다.
3. 모든 참가자가 공통 카운트다운 뒤 같은 20개 메뉴와 조건으로 플레이한다.
4. 제출된 결과를 모아 1등부터 최대 8등까지의 순위와 포획 메뉴를 표시한다.
5. 1등의 포획 메뉴, 가장 많이 겹친 메뉴, 꼴찌와 식사 내기 결과를 확인한다.

## 점수와 플레이 피드백

절단선이 음식 판정 영역을 나눈 두 면적을 `A`, `B`라고 할 때 정확도는 다음과 같다.

```text
정확도 = 100 × (1 - |A - B| ÷ (A + B))
```

베기 정확도는 소수 첫째 자리로 반올림해 다음 네 단계의 문구와 색상으로 즉시 표시한다. 등급은 화면에 표시된 정확도를 기준으로 하며 연출만 바꾸고 실제 정확도와 평균 점수 계산은 바꾸지 않는다.

| 정확도 | 판정 문구 |
|---:|---|
| 95 이상 | `칼각!` |
| 80 이상 95 미만 | `훌륭해요!` |
| 60 이상 80 미만 | `좋아요!` |
| 60 미만 | `아쉬워요` |

아직 베거나 놓친 비포획 음식이 없으면 HUD에 `현재 평균 —`를 표시한다. 포획만 한 상태에서도 평균을 0점으로 오해하지 않게 하기 위한 표기다. 첫 베기 또는 놓침 이후부터 숫자 평균을 표시한다.

음식이 기준선에 가까워지면 코럴색 기준선이 점멸하고, 베기나 포획 동작 중이 아닐 때 `놓치기 직전` 안내를 표시한다. 끝내 처리하지 못하면 `MISS · 0점` 팝업과 화면 반응을 표시하고, 해당 음식은 평균 계산의 0점 항목으로 포함한다.

16번째 음식이 나오기 전에는 `FINAL 5` 배너로 마지막 다섯 개와 속도 상승을 알린다. 배너가 끝나면 남은 플레이가 계속된다.

최종 평균은 포획하지 않은 음식만을 분모로 사용한다.

```text
최종 평균 = 비포획 메뉴의 점수 합 ÷ 비포획 메뉴 수
```

- 놓친 비포획 메뉴는 0점으로 분자와 분모에 포함한다.
- 포획 메뉴는 취향 표현이므로 분자와 분모에서 제외한다.
- 포획하지 않아도 불이익은 없다.
- 같은 표시·제출 점수는 공동 순위로 처리한다.

## 종료 조건과 결과

20개 메뉴가 모두 베기, 포획 또는 놓침으로 처리되면 한 판이 끝난다.

혼자 하기에서는 평균 정확도와 포획 메뉴를 보여준다. 방 플레이에서는 전체 순위, 각 참가자의 포획 메뉴 0~2개, 1등의 포획 메뉴, 가장 많이 겹친 메뉴, 꼴찌와 고정 식사 내기 안내를 보여준다. 게임은 최종 식사 메뉴를 자동 확정하지 않는다.
